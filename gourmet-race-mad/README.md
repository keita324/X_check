# グルメレースMAD（M!LK素材）

- `gourmet_race_mad.mp4` … 完成動画（1280x720 / 30fps / 約70秒）

## 作り方
1. 音源から主旋律とベースを音符として抽出（basic-pitch）→ `scripts/bp.py`, `sky.py`, `score.py`
2. 素材動画を文字起こし（faster-whisper）し、demucsで声だけを分離してフレーズを特定 → `scripts/tr.py`, `samples.py`
3. 声を WORLD ボコーダで音符ごとの音程と長さに合わせる（Aメロ・Bメロは1オクターブ下、ベースは2オクターブ上）→ `scripts/tune.py`
4. 音符の頭ごとにカットを切り替え、小節頭で白フラッシュ・ズーム、ベースパートでタイル・反転などのエフェクト → `scripts/build.py`, `render.py`

構成（v2・同じセリフを繰り返す版）: イントロ（ララララミルク）→ Aメロ「幸せって2種類あんねん」を1音ずつ歌わせて連呼、締めに「キモいです」→ ベースのブレイクは「俺」連打＋「せーの」→ Bメロ「キモいです」連呼（途中「何これ?」）→ 最後にもう一度「幸せって…」→ 半音ずつ上がる「俺」連打 → 「言われてねぇ」でオチ（最後の文字なし）


## v3
- 音程補正は一部（Aメロ頭・Bメロ中盤の「幸せって…」「キモいです」）だけ。他は地声のまま、声の頭を詰めて次の音符でスパッと切る刻み方式
- 声が鳴っている間はBGMを下げて声を前に出す
- 左右反転は廃止し、顔検出で顔ドアップにズームする演出に変更
- 生成スクリプト: `scripts/build3.py`

- ベースのブレイクでもジャンケンを刻み、「うぉほほほ!」で締める
- 1:50「ヴぁわあー!」と2:15の叫び声を小節締め（Aメロ末尾・ベース・Bメロ）に投入（叫びは音程がないので地声のまま）
- 笑っているだけの素材（バーッ / Yes or No / いけるな 等）を外し、セリフのはっきりした素材に差し替え
- 生成スクリプト: `scripts/build4.py`
